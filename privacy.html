Privacy Policy - rclone-kamera

Last updated: 5 November 2026

  • Who uses it: only its owner, for personal purposes.
  • What it can access: it uses the Google Drive drive.file scope, so it can only access files and folders that it created itself. It cannot see any other file in the Google Drive.
  • What it does: it uploads video files from the owner's computer to one folder in the owner's Google Drive and deletes files older than 90 days from that folder.
  • Sharing: no data is sent to the developer or to any third party. Google user data is not sold, shared, or used for advertising. Data moves only between the owner's computer and the owner's Google Drive.
  • Storage: the access token is stored only on the owner's computer.
  • Revoking access: at any time at myaccount.google.com/permissions.
  • The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
